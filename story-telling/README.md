# ✨ Story Telling

A cinematic and immersive story-telling website built with **React and Vite**.  
The project focuses on creating a smooth scrolling experience with animated chapters, visual storytelling, transitions, and a cinematic UI.

## 🌐 Live Demo

🔗 [View Live Website](https://hog-warts-story-telling.vercel.app/)

## 📸 Features

- 🎬 Cinematic storytelling experience
- 📖 Chapter-based story sections
- ✨ Smooth reveal animations
- 🖼️ Full-screen visual scenes
- 🎭 Character and story transitions
- 🌊 Smooth scrolling experience
- 📱 Responsive design
- 🧭 Animated navigation bar
- 🎞️ Final story ending section
- 🦶 Custom footer section

## 🛠️ Tech Stack

- **React.js**
- **Vite**
- **JavaScript**
- **Tailwind CSS**
- **Locomotive Scroll**
- **Framer Motion**
- **React Icons**
